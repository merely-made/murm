# webrtc-ping

C1 headed receipt for the browser WebRTC carrier (`murm-webrtc`): a real browser
data channel against a native str0m answerer over a loopback signalling fixture.
Run with `run.ps1`. It has its own workspace root and lock.

Origin: Mere's former `crates/probes/webrtc-ping`, kept as an untracked local
probe until it moved here.
