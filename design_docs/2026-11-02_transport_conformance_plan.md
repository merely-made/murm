# Transport standards and retained repair conformance

**Status, 2026-11-02: plan.** Successor to `archive_docs/2026-11-02/2026-10-11_transport_conformance_plan.md`; the original is archived whole.

## Open phases and done conditions

- **TC1 codec breadth:** extend independent RFC 6330 comparisons beyond the selected OpenRQ `Al=1, N=1` profile to selected alignment, sub-block, ESI and resource boundaries. Name versions, requirements, restrictions and independent lineages.
- **TC2 portable corpus:** specify capability, reset, bytes, virtual time, event, checkpoint and resource interfaces for external processes; register stock RNS and real independent QUIC peers. Preserve provenance/licenses and distinguish unsupported, skipped, timeout, infrastructure and failure results.
- **Lane B:** prepare a semantic mutation once; retry with a fresh caller counter after a lost provisional response and reconnect; prove the original result is returned without a second apply through the actual client and board owner.
- **TC3–TC4 evaluation:** after contracts stabilize, evaluate incremental retained repair, exact inventory and signed admission over additional real carriers, restarts and resource pressure. Keep reconstruction, link delivery, admission and application effects separate. A Reticulum carrier needs the existing accepted session-proof boundary; native UI, workers and RF are separate.
- **Radio framing:** choose and validate smaller symbols or fragmentation before radio adaptation; the existing signed T=128 host frame is 275 bytes, exceeding Selvage's 255-byte limit. Separate accepted queueing from actual transmission and admission.
- **TC5–TC6 device and physical:** on named targets measure peak heap/stack, CPU, retained storage and radio coexistence; then named boards/firmware/antennas/instruments measure useful goodput, range, isolation, retune/clock cost, collision, power and airtime under stated legal/PHY conditions. A modeled rate does not establish physical performance.
- **TC7 optional adapters:** select actual peers and needs before choosing FLUTE/ALC, NORM, BPv7, SCHC/LoRaWAN, CoAP/OSCORE or MLS; each selected profile needs its own requirements and independent interoperability. They are alternatives, not a mandatory aggregate backlog.

## Constraints

Authenticate before expensive decoding where the bearer permits; bind manifests, identities, coding and retention, while preserving original signed bytes and domain admission. Bound generations, symbols, decoder work and storage; finite-capacity catch-up is conditional. Actual PHY scheduling is project work, not automatically a standard profile. Model and physical evidence stay distinct.

## Findings, 2026-11-02

Broader conformance, cross-host/service, embedded and RF claims remain separate.
